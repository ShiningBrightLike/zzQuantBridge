# A 股多因子选股模型

## 目标

从可配置的 A 股股票池中，按当前交易日可见的量价因子计算横截面综合得分，选取得分较高且满足流动性、上市时间和仓位约束的股票。选股结果只进入统一的目标仓位接口，不直接下单。

## 数据与股票池

- 默认从 AkShare 获取全 A 股当前列表，排除 ST、退市、北交所、停牌和成交额过低的股票。
- 先按最新成交额保留候选池，再按每日动态的 60 日平均成交额保留约 800 只；`universe.candidate_pool_size: 0` 表示候选池自动取 `max_symbols * 2`，显式设置可扩大候选池，`universe.max_symbols` 控制最终研究池。
- 回看至少 5 年日线数据，以覆盖 120 日预热、504 日训练窗口和 20 日标签期限。
- 量价因子使用前复权收盘价；下载任务会额外保存最近 10 个交易日的未复权收盘价为 `execution_close`，实际执行参考价由建议层使用该列。若缺少未复权执行价，建议运行会被阻断。
- 当前快照只能提供当前仍上市的股票，回测仍存在幸存者偏差；退市股票数据留待后续接入。
- 质量闸门会检查每个标的首次到末次观测之间的缺失 bar；默认允许最多 20 个缺失日且缺失比例不超过 2%，超过阈值时选股/回测/建议运行进入 `BLOCKED`。这是为了兼容未登记的停牌，严格停牌清单可在后续数据源中补充。

## 因子

第一版只使用当前及历史量价数据。因子方向不预设，由训练窗口的 IC 符号决定。

| 分组 | 因子 | 定义 |
| --- | --- | --- |
| 动量 | `momentum_20/60/120` | 过去 20/60/120 个交易日收益率 |
| 反转 | `reversal_5` | 过去 5 个交易日收益率 |
| 波动 | `volatility_20/60` | 20/60 日收益率标准差 |
| 波动 | `downside_vol_20` | 20 日负收益波动 |
| 波动 | `max_drawdown_60` | 60 日滚动最大回撤 |
| 流动性 | `liquidity_20` | 20 日平均成交额的对数 |
| 流动性 | `volume_change_5_60` | 5 日平均成交量相对 60 日均量的变化 |
| 流动性 | `amihud_20` | 20 日 Amihud 非流动性 |
| 分布 | `skew_60` | 60 日收益率偏度 |
| 分布 | `turnover_volatility_20` | 20 日成交量变异系数 |
| 技术 | `rsi_14` | 14 日 RSI |
| 技术 | `macd_hist` | MACD 柱线除以收盘价 |
| 技术 | `bollinger_position_20` | 收盘价相对 20 日布林带的位置 |
| 技术 | `distance_high_252` | 收盘价相对 252 日最高价的距离 |
| 技术 | `price_volume_corr_20` | 20 日收益与成交量变化的相关系数 |

参考案例中的展期收益、基差、持仓量和仓单因子没有直接移植。它们依赖期货合约结构和期货专属数据，不是 A 股的可比特征。

## 训练与权重

1. 对每个股票计算未来 20 个交易日收益，作为训练标签。
2. 每个调仓日只使用 `label_end <= 调仓日` 的标签。这样，训练窗口末尾尚未实现的收益不会进入模型。
3. 在每个交易日截面上计算因子值与标签的 Spearman IC。
4. 统计 IC 均值、IC 标准差、ICIR、IC 胜率和前后半段符号稳定性。
5. 过滤 IC 天数、`|IC_mean|` 和 `|ICIR|` 不达标的因子；严格筛选没有结果时，使用有足够 IC 天数的因子并标记 `fallback_used`。
6. 因子权重为：

```text
w_i = sign(IC_mean_i) * |ICIR_i|^0.5 / sum_j(|ICIR_j|^0.5)
```

权重符号表示因子方向；负权重表示该因子值越低越好。

## 打分与选股

- 每个调仓日对因子做 1%/99% 缩尾和横截面 z-score。
- 综合得分是已选因子 z-score 与权重的加权和。
- 默认持有前 20 名，单只最高 5%，现金缓冲 10%，每 20 个交易日调仓。
- 默认只选择综合得分不小于 0 的股票；合格标的不足时保留现金，不用负分股票填满 Top-N。
- 已有持仓排名仍在前 30 名时保留，减少不必要的换手。
- 默认要求每只入选股票至少能买入 1 手（100 股）；每只股票的预算按组合市值、`top_n` 和现金缓冲估算，价格过高的股票会被过滤，避免目标仓位无法落到实际成交。
- 股票池在历史日期按当时的上市天数、60 日平均成交额和成交额排名动态确定。

## 回测

- 信号在调仓日收盘后产生，默认下一交易日开盘执行。
- 多因子横截面回测在独立的目标权重模拟器中执行；基线信号策略仍使用 vectorbt。设计理由见 [ADR 0004](adr/0004-cross-sectional-backtest-engine.md)。
- 回测默认要求至少 504 个交易日的有效样本外区间；不足时仍保留结果文件，但运行状态为 `BLOCKED`。被跳过的调仓会写入 `skipped_rebalances.csv`。
- 按 100 股整数手交易，计入手续费和滑点。
- 输出组合净值、回撤、交易记录、成本敏感性和信号延迟敏感性。
- `average_invested_weight` 展示平均持仓市值占比，便于识别现金拖累。
- 基准为股票池等权日收益。

## 使用

准备历史快照：

```bash
python -m quant download \
  --config configs/multifactor.yaml \
  --start 2021-10-01 \
  --end 2026-10-18
```

运行选股和回测：

```bash
python -m quant select-stocks --config configs/multifactor.yaml
python -m quant backtest --config configs/multifactor.yaml
python -m quant generate-signals --config configs/multifactor.yaml
```

只使用已有静态标的池时，把 `configs/universe.yaml` 的 `mode` 设为 `config`，或在命令行传入 `--universe-mode config`。

## 运行产物

- `factor_snapshot.csv`：最新横截面的原始因子、z-score、综合得分和排名。
- `factor_weights.csv`：当前模型的因子方向、权重和 IC/ICIR 统计。
- `selections.csv`：当前调仓日入选标的和目标权重。
- `model_metadata.json`：模型版本、训练窗口、入选数量以及是否受整手预算限制。
- `signals.csv`：统一目标仓位接口格式。
- `backtest_metrics.json`、`equity_curve.csv`、`trades.csv`：样本外回测结果。
- `backtest_model_metrics.csv`、`backtest_factor_weights.csv`、`backtest_selections.csv`：逐调仓日的历史模型记录。
- `report.html`：可审阅的 HTML 报告。

## 已知限制

- 当前股票池来自当前仍上市的 A 股，不能完全消除退市幸存者偏差。
- 尚未接入财务、估值和点时行业数据，因此模型是量价多因子模型，不包含价值/质量因子。
- 20 日前瞻收益的相邻标签存在重叠，IC 标准差和 ICIR 不是独立样本推断。
- 回测使用当前可获得的复权行情快照，除权事件和长期停牌仍需在数据层进一步处理。
- 同一行情快照只保存一种复权口径；因子研究可用前复权数据，但生成实际建议前必须用未复权行情核对执行参考价。
