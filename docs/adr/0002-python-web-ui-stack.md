# ADR 0002：采用 FastAPI、Jinja2/HTMX 和 Plotly 作为第一版 Web UI

- 状态：已接受
- 日期：2026-10-10

## 背景

项目是单用户、本机运行的人工交易辅助系统。现有核心能力是 Python CLI、数据适配器、策略、组合账本和交易建议，尚未有 Web 框架。第一版需要快速提供可审阅的研究和组合界面，同时保留未来拆分 API 或替换前端的空间。

## 决策

使用 FastAPI 提供 HTTP 服务，Jinja2 渲染页面，浏览器原生 `fetch` 处理局部交互，Plotly 提供交互式图表。页面路由调用应用服务，不直接操作 argparse 或复制领域规则。服务默认绑定 `127.0.0.1`，支持触发研究、查看结果和成交回录，不提供自动下单能力。任务在进程内单 worker 执行，成交写入使用 CSRF 保护和确认后的 SQLite 事务。

## 后果

Python 代码可以复用现有模块，首版无需维护独立前端构建链。原生 fetch 交互复杂度和大型单页应用相比更低，但如果未来出现多用户、实时协作或复杂客户端状态，需要增加 API 版本、认证和独立前端。
