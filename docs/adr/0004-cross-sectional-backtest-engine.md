# 横截面多因子使用确定性目标权重模拟器

- 状态：已接受
- 日期：2026-10-18

## 背景

项目原有回测入口使用 vectorbt 的信号回测。多因子选股产生的是逐日目标权重，还需要按 A 股 100 股整数手、目标权重和现金约束模拟成交。vectorbt 的信号回测接口不能直接表达完整目标权重语义，且当前版本的聚合统计对 NumPy/Pandas 新版本存在兼容性问题。

## 决策

基线均线策略继续使用 vectorbt 回测。多因子策略使用 `src/quant/backtest/multifactor.py` 中的确定性目标权重模拟器：在调仓后的下一交易日开盘按目标权重交易，按整数手取整，计入手续费和滑点，并记录现金、持仓市值、逐笔交易和换手。多因子运行同时保存完整的因子权重、调仓选择和回测指标，便于复现。

## 后果

系统同时维护两个回测边界，指标不能直接假设与 vectorbt 完全一致。多因子回测的成交和现金规则由本项目测试固定；如果未来改用 vectorbt 的 `Portfolio.from_orders`，必须先用同一快照做结果对照，再替换模拟器。
