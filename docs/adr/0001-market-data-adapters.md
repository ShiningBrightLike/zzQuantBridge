# ADR 0001：通过可替换适配器隔离 A 股行情来源

- 状态：已接受
- 日期：2026-10-08

## 背景

系统需要获取 A 股日线行情，同时必须支持离线回测、固定数据快照和数据源故障阻断。AkShare 可以免费获取公开数据，但请求稳定性和访问限制不受本项目控制。

## 决策

使用统一的 `MarketDataProvider` 接口隔离数据源。第一版提供：

1. 本地 CSV/Parquet 适配器，用于可复现研究和测试；
2. AkShare 可选适配器，用于在线下载和原始数据归档。

AkShare 不作为核心安装依赖。在线请求失败或数据过期时，建议流程 fail-closed，不静默回退到未校验的旧数据。

## 后果

策略、回测和组合层不需要知道数据来自哪里，测试可以完全离线。需要为不同数据源维护字段映射、复权信息和质量检查；在线适配器还需要处理限流和接口变化。
